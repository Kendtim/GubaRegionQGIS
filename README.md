Geological Mapping with QGIS

Project Overview

This project presents a geological mapping and spatial visualization workflow developed using QGIS.

Objectives

* Visualize geological or spatial data.
* Organize and display GIS layers.
* Produce a map with a legend, scale bar, and coordinate reference system.

Tools

* QGIS
* Shapefile vector data
* Coordinate Reference Systems (CRS)
* GIS cartography and map layout design

Repository Contents

* Project.qgz — QGIS project file
* Final_Map1_Rahimzade_Farhad.png — exported maps in PNG format

How to Open

1. Download or clone this repository.
2. Open the .qgz project file in QGIS.
3. If necessary, update the data paths.
